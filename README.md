# Бар-менеджер AI

Персональный PWA-ассистент для управления рабочими задачами заведений «Оксфорд» и «Современник».

## Текущий этап

Первая опубликованная версия — интерактивный frontend-прототип с локальным хранением задач, центром уведомлений, Telegram-входящими и панелью ИИ-помощника.

## Архитектура рабочей версии

- PWA frontend;
- backend API;
- PostgreSQL;
- Telegram Bot API webhook;
- OpenAI API и агентная логика;
- планировщик сроков;
- Web Push;
- журнал действий и подтверждений.

Секреты не хранятся в репозитории и передаются только через переменные окружения.
